### MemOnce: A Scalable Memory Architecture for Large Language Models

**中文标题：** MemOnce：适用于大型语言模型的可扩展内存架构

**摘要：** Deploying large language models (LLMs) in long-horizon and continual interactions requires maintaining reusable memory states for future inference, posing challenges for existing architectures. Standard Transformers accumulate layer-wise, token-level KV caches, incurring linear GPU memory growth and quadratic computational complexity as the context expands. In contrast, linear-time architectures compress history into fixed-size states, but struggle to retain fine-grained details. We introduce MemOnce, a foundation architecture that learns scalable memory states for language models. MemOnce is based on two core designs: (a) Memory encoder-decoder: it caches only a small subset of final-layer hidden states as compact memory representations and dynamically decodes them back into KV caches for attention layers; (b) Memory sparse attention: for each continual input, MemOnce adaptively retrieves relevant memory representations, with the sparse indices computed only once across layers. Coupling these two designs enables efficient on-the-fly memory loading and KV cache decoding, drastically reducing the GPU memory footprint and achieving linear-time complexity. We conduct extensive experiments to show that MemOnce outperforms Transformers and other architectures across varying model sizes, context lengths, and training paradigms (pretraining and post-training adaptation). In particular, adapting Qwen3.5-4B with MemOnce reduces memory state cache by 1313$\times$ and prefill latency by 6.9$\times$ at 1M context, and improves throughput by 3.5$\times$ and overall memory performance by +5.77%. Finally, MemOnce generalizes zero-shot to downstream representation tasks, achieving competitive results against specialized models.

**摘要翻译：** 在长期和持续交互中部署大型语言模型 (LLM) 需要维护可重用的内存状态以供未来推理，这对现有架构提出了挑战。标准 Transformer 累积分层、令牌级 KV 缓存，随着上下文扩展，会导致 GPU 内存线性增长和二次计算复杂性。相比之下，线性时间架构将历史压缩为固定大小的状态，但很难保留细粒度的细节。我们引入 MemOnce，这是一种学习语言模型可扩展内存状态的基础架构。 MemOnce 基于两个核心设计：（a）内存编码器-解码器：它仅将最终层隐藏状态的一小部分缓存为紧凑的内存表示，并将它们动态解码回 KV 缓存以用于注意层； (b) 内存稀疏注意力：对于每个连续输入，MemOnce 自适应地检索相关的内存表示，稀疏索引仅跨层计算一次。将这两种设计结合起来可以实现高效的动态内存加载和 KV 缓存解码，从而大大减少 GPU 内存占用并实现线性时间复杂度。我们进行了大量的实验，证明 MemOnce 在不同的模型大小、上下文长度和训练范例（训练前和训练后适应）方面优于 Transformer 和其他架构。特别是，在 Qwen3.5-4B 上采用 MemOnce，在 1M 上下文中，内存状态缓存减少了 1313$\times$，预填充延迟减少了 6.9$\times$，吞吐量提高了 3.5$\times$，整体内存性能提高了 +5.77%。最后，MemOnce 将零样本推广到下游表示任务，实现了与专用模型竞争的结果。

### QuantStream3D: Geometry-Aligned Low-Bit KV Cache Quantization for Streaming Visual Geometry Transformers

**中文标题：** QuantStream3D：用于流式视觉几何变换器的几何对齐低位 KV 缓存量化

**摘要：** Streaming visual geometry transformers retain historical key-value (KV) states as cross-view geometric memory, but growing caches constrain long-sequence inference. We systematically characterize KV quantization in streaming geometry and uncover two linked challenges: Nonuniform Geometric Sensitivity and Cache-Geometry Mismatch. Quantization sensitivity varies across precision choices and cache locations, while perturbed retrieval changes geometry-head inputs and propagates through subsequent predictions and KV writes. Guided by these findings, we propose QuantStream3D, to our knowledge the first dedicated KV quantization framework for streaming visual geometry transformers. Geometry-Guided Mixed-Precision KV Quantization protects sensitive cross-view evidence, while Geometry-Aligned Quantization-Aware Distillation jointly adapts transformer blocks and geometry heads on student-generated quantized history. Across five benchmarks and two backbones, QuantStream3D achieves near-lossless geometric accuracy in most settings with predominantly 2-bit KV caches, and many configurations surpass unquantized inference. Compared with LLM-oriented KV quantizers, it reduces TUM absolute trajectory error and NeuralRGBD completeness error by up to 57.4% and 69.7%, respectively. Integration with existing native cache-pruning methods further pushes compression while improving reconstruction quality on NeuralRGBD. Our optimized StreamVGGT backend achieves $5.05\times$ physical KV compression and 23.1% lower latency at batch size one. Under a fixed memory budget on the same GPU, it supports $5.4\times$ the maximum batch size and up to $1.67\times$ the peak throughput of unquantized inference. Code and pretrained checkpoints will be made publicly available.

**摘要翻译：** 流式视觉几何变换器保留历史键值（KV）状态作为跨视图几何内存，但不断增长的缓存限制了长序列推理。我们系统地表征了流几何中的 KV 量化，并揭示了两个相关的挑战：非均匀几何灵敏度和缓存几何不匹配。量化灵敏度因精度选择和缓存位置而异，而扰动检索会改变几何头输入并通过后续预测和 KV 写入进行传播。在这些发现的指导下，我们提出了 QuantStream3D，据我们所知，这是第一个用于流式视觉几何变换器的专用 KV 量化框架。几何引导混合精度 KV 量化可保护敏感的交叉视图证据，而几何对齐量化感知蒸馏则根据学生生成的量化历史共同调整变压器块和几何头。在五个基准测试和两个骨干网中，QuantStream3D 在大多数主要使用 2 位 KV 缓存的设置中实现了近乎无损的几何精度，并且许多配置超越了非量化推理。与面向LLM的KV量化器相比，它分别将TUM绝对轨迹误差和NeuralRGBD完整性误差降低了高达57.4%和69.7%。与现有本机缓存修剪方法的集成进一步推动压缩，同时提高 NeuralRGBD 的重建质量。我们优化的 StreamVGGT 后端在批量大小为 1 时实现了 5.05 美元\次$物理 KV 压缩和 23.1% 的延迟降低。在同一 GPU 上的固定内存预算下，它支持 $5.4\times$ 最大批量大小，以及高达 $1.67\times$ 的非量化推理峰值吞吐量。代码和预训练检查点将公开。

### The Dual-Tier Sentiment Framework: Scalable Multimodal UX Attribution in Web Search

**中文标题：** 双层情感框架：网络搜索中可扩展的多模式用户体验归因

**摘要：** Sustaining user experience (UX) quality in large-scale web search requires scalable evaluation. Traditional surveys are slow and bottleneck rapid A/B testing, while automated metrics often lack the granularity to diagnose visual-spatial UX anomalies. To address this, we introduce the Dual-Tier Sentiment Framework, a novel industrial architecture for automated UX attribution. Tier 1 (Macro System) acts as a scalable user sentiment regression detector, utilizing a fine-tuned encoder-decoder LLM (based on Gemini XS) on telemetry features. Through multi-task regularization and contextual feature engineering, this tier achieves a +9.8% PR-AUC gain on over 500,000 held-out records, matching baseline recall on all validated regressions with $\sim$20% relative precision gain among the 12 held-out experiments. In production, it reduces measurement latency from weeks to hours and cuts survey overhead by over 40%. Tier 2 (Micro System) provides granular diagnostics by employing a Multimodal LLM (Gemini 3.0 Pro) to natively assess visual renderings and spatial layout of web result blocks, quantifying "User Toil" as the estimated effort required to reach a satisfactory result. Enhanced by RL-based automated prompt optimization and an AI judge for win/loss patterns, the MLLM yields a $>$6.5% F1 score improvement, offering deep insights into content quality and layout friction. Ultimately, this framework enables scalable, accurate, and diagnostic UX attribution, processing O(100k) live experiment queries daily.

**摘要翻译：** 在大规模网络搜索中维持用户体验 (UX) 质量需要可扩展的评估。传统调查速度缓慢，并且阻碍了快速 A/B 测试，而自动化指标通常缺乏诊断视觉空间用户体验异常的粒度。为了解决这个问题，我们引入了双层情感框架，这是一种用于自动用户体验归因的新颖工业架构。第 1 层（宏系统）充当可扩展的用户情绪回归检测器，利用遥测功能上的微调编码器-解码器 LLM（基于 Gemini XS）。通过多任务正则化和上下文特征工程，该层在超过 500,000 个保留记录上实现了 +9.8% 的 PR-AUC 增益，将所有经过验证的回归的基线召回率与 12 个保留实验中 $\sim$20% 的相对精度增益相匹配。在生产中，它将测量延迟从数周缩短至数小时，并将调查开销减少 40% 以上。第 2 层（微系统）通过采用多模式 LLM (Gemini 3.0 Pro) 来提供精细诊断，以本地评估 Web 结果块的视觉渲染和空间布局，将“用户辛苦”量化为达到满意结果所需的估计工作量。通过基于 RL 的自动提示优化和 AI 判断输赢模式的增强，MLLM 的 F1 分数提高了 6.5% 以上，提供了对内容质量和布局摩擦的深入洞察。最终，该框架实现了可扩展、准确和诊断性的 UX 归因，每天处理 O(100k) 次实时实验查询。

### LesionAgent: Training-Free Agentic Tumor Tracking and Response Assessment in Longitudinal CT

**中文标题：** LesionAgent：纵向 CT 中的免培训代理肿瘤跟踪和反应评估

**摘要：** Every few months, a cancer patient's CT scans decide whether treatment continues. 3D foundation models can now detect, segment, register and track lesions, yet none of them reads the scans as a radiologist does. A radiologist decides which findings are lesions, which are the same lesion months later and whether a new spot means progression, and checks each decision against the extensive rules of a clinical guideline. We introduce LesionAgent, an LLM agent that performs this read end to end without task-specific training. It operates frozen 3D models as tools, acts in 3D through coordinate-labelled views, remembers every lesion across visits in a registry, verifies every model output it relies on, and leaves every number to a deterministic guideline engine. On four public longitudinal CT datasets, LesionAgent tracks more lesions and measures them more accurately than every automatic baseline, and where the same 3D models chained by fixed rules call progression falsely at 33 of 56 follow-ups, it does so twice. On clinical follow-up CTs, it agrees with the radiologists' response at 20 of 23 follow-ups, including every change in response, and without training on DeepLesion, it retrieves more of its lesions than every tracker trained on it (89.0% vs. 87.4%). Its harness, not its LLM, makes the difference: given the same LLM and 3D models but not the harness, Claude Code reaches a detection F1 of 41% and LesionAgent 78%, and an open-weight LLM that can run inside the hospital rises from 6% to 73%. LesionAgent and a napari reading app for any LLM are available at https://github.com/MIC-DKFZ/LesionAgent.

**摘要翻译：** 每隔几个月，癌症患者的 CT 扫描就会决定是否继续治疗。 3D 基础模型现在可以检测、分割、记录和跟踪病变，但它们都不能像放射科医生那样读取扫描结果。放射科医生决定哪些发现是病变，哪些是几个月后的相同病变，以及新的斑点是否意味着进展，并根据临床指南的广泛规则检查每个决定。我们引入了 LesionAgent，这是一种 LLM 代理，无需特定于任务的培训即可执行端到端的读取。它将冻结的 3D 模型作为工具进行操作，通过坐标标记视图以 3D 方式进行操作，记住注册表中访问期间的每个病变，验证其依赖的每个模型输出，并将每个数字留给确定性指南引擎。在四个公共纵向 CT 数据集上，LesionAgent 跟踪更多病变并比每个自动基线更准确地测量它们，并且由固定规则链接的相同 3D 模型在 56 个随访中的 33 个中错误地调用了进展，它这样做了两次。在临床随访 CT 上，它在 23 次随访中的 20 次中与放射科医生的反应一致，包括反应的每一次变化，并且在没有经过 DeepLesion 训练的情况下，它检索到的病灶比每个接受过训练的跟踪器都多（89.0% 与 87.4%）。是它的线束，而不是它的法学硕士，造成了差异：给定相同的法学硕士和 3D 模型，但没有线束，Claude Code 的检测 F1 达到 41%，LesionAgent 达到 78%，而可以在医院内运行的开放式法学硕士则从 6% 上升到 73%。 LesionAgent 和适用于任何法学硕士的 napari 阅读应用程序可在 https://github.com/MIC-DKFZ/LesionAgent 上找到。

### Who Grades the Agent? Privilege Separation for Coding-Agent Benchmarks

**中文标题：** 谁给代理人评分？ Coding-Agent 基准的权限分离

**摘要：** Benchmarks for AI-based coding agents are a staple of the current AI landscape, because they are the leading way to measure the performance of LLMs. Their scores guide business and research decisions. Evaluating coding agents is challenging, since they are able to manipulate their evaluation infrastructure to artificially achieve better scores. Grading an agent's solution often requires running its code, which can then manipulate the evaluation process. BenchJack, an automated benchmark auditor, recently reached near-perfect scores on nine of ten popular agent benchmarks without actually solving their tasks. Agents already do this unprompted, as OpenAI's July 2026 Hugging Face incident showed.
  Building on secure systems design, we introduce SplitBench, a privilege separation framework for evaluating coding agents and the first in the scientific literature to separate running a task's tests from judging their results. Even an agent whose code takes over the entire test environment cannot forge a pass, because a trusted grader holds the expected answers. We show that real-world benchmarks (e.g., Terminal-Bench, DeepSWE) can be ported to the SplitBench framework with minimal effort and high fidelity: 180 of 202 tasks convert, and SplitBench agrees with the native graders on 98.7% of agent attempts. We attack the converted tasks in the worst case, where adversarial agents can read all the grading code but not the expected answers. SplitBench blocked 75% of their attempts; the rest mostly reveal weaknesses in the original tasks' tests rather than flaws in SplitBench.

**摘要翻译：** 基于人工智能的编码代理的基准是当前人工智能领域的主要内容，因为它们是衡量法学硕士表现的主要方法。他们的分数指导商业和研究决策。评估编码代理具有挑战性，因为它们能够操纵其评估基础设施来人为地获得更好的分数。对代理的解决方案进行评分通常需要运行其代码，然后可以操纵评估过程。 BenchJack 是一名自动基准审核员，最近在 10 个流行的代理基准测试中的 9 个上取得了近乎完美的分数，而没有实际解决他们的任务。正如 OpenAI 2026 年 7 月的 Hugging Face 事件所表明的那样，特工们已经在无提示的情况下这样做了。
  基于安全系统设计，我们引入了 SplitBench，这是一个用于评估编码代理的权限分离框架，也是科学文献中第一个将运行任务测试与判断其结果分开的框架。即使代码接管整个测试环境的代理也无法伪造通行证，因为受信任的评分者掌握着预期的答案。我们表明，现实世界的基准（例如，Terminal-Bench、DeepSWE）可以以最少的努力和高保真度移植到 SplitBench 框架：202 个任务中的 180 个进行转换，SplitBench 在 98.7% 的代理尝试上与本地评分者一致。我们在最坏的情况下攻击转换后的任务，其中敌对代理可以读取所有评分代码，但无法读取预期答案。 SplitBench 阻止了 75% 的尝试；其余的大部分揭示了原始任务测试中的弱点，而不是 SplitBench 中的缺陷。

### Beyond Self-Critique: Epistemic Convergence Control for Multi-Agent Research Verification

**中文标题：** 超越自我批评：多智能体研究验证的认知收敛控制

**摘要：** Multi-agent systems for scientific claim verification increasingly rely on role-structured LLM debate to pressure-test hypotheses. However, when debating agents are instantiated from the same underlying base model, they share identical latent representations, making self-critique bias structurally inevitable. Static fixed-iteration protocols compound this by either halting prematurely before evidence stabilizes or wasting inference compute after convergence. We present \sys{}, a multi-agent research verification framework that addresses both failure modes. First, we introduce an asymmetric role architecture comprising an Advocate, Skeptic, and Arbitrator with opposing epistemic directives, producing significantly lower role-embedding similarity (0.852 vs.\ 0.918 for symmetric Multi-Agent Debate [MAD], $p = 5.82 \times 10^{-8}$) and surfacing more contested claims (22.0\% vs.\ 15.4\%). Second, we propose the Belief-Delta ($\DB$) convergence criterion, an evidence-grounded stopping rule that eliminates over-iteration (0.0\% vs.\ 62.5\% for Fixed-$3$) while cutting LLM calls by 2.4$\times$. Third, each supported claim is anchored to a verbatim literature snippet audited by an independent NLI classifier, achieving a 21.7\% hallucination rate (comparable to 25.9\% for a Self-Refine critic, $p = 0.61$) while establishing auditable evidence grounding. Across 200 runs on 40 research hypotheses evaluated with DeepSeek-R1-32B, \sys{} balances compute efficiency with rigorous epistemic verification.

**摘要翻译：** 用于科学主张验证的多智能体系统越来越依赖于角色结构的法学硕士辩论来对假设进行压力测试。然而，当辩论代理从相同的底层基础模型实例化时，它们共享相同的潜在表示，使得自我批评偏见在结构上不可避免。静态固定迭代协议通过在证据稳定之前过早停止或在收敛后浪费推理计算来加剧这种情况。我们提出 \sys{}，一个解决这两种故障模式的多代理研究验证框架。首先，我们引入了一种非对称角色架构，包括具有相反认知指令的倡导者、怀疑论者和仲裁者，产生显着较低的角色嵌入相似性（对称多代理辩论 [MAD] 为 0.852 vs.\ 0.918，$p = 5.82 \times 10^{-8}$），并呈现更多有争议的主张（22.0\% vs.\ 15.4\%）。其次，我们提出了 Belief-Delta ($\DB$) 收敛标准，这是一种基于证据的停止规则，可以消除过度迭代（Fixed-$3$ 为 0.0\% vs.\ 62.5\%），同时将 LLM 调用减少 2.4$\times$。第三，每个支持的主张都基于由独立 NLI 分类器审核的逐字文献片段，实现了 21.7% 的幻觉率（与 Self-Refine 批评家的 25.9% 相比，$p = 0.61$），同时建立了可审核的证据基础。在使用 DeepSeek-R1-32B 评估的 40 个研究假设的 200 次运行中，\sys{} 在计算效率与严格的认知验证之间取得了平衡。

**摘要：** Financial documents combine narrative disclosures, accounting metrics, corporate structures, management commentary, and time-dependent facts, making them difficult to represent using conventional chunk-based retrieval-augmented generation systems. This paper presents an auditable, schema-driven methodology for constructing temporal financial knowledge graphs from page-delimited documents parsed using a general purpose document intelligence service. Overlapping document windows undergo phased large language model extraction of structural entities, quantitative observations, and domain-specific relationships. Candidate graph elements are validated against predefined schemas and consolidated through scope-aware exact, normalized, fuzzy, embedding-based, and LLM-assisted entity resolution. Temporal merge constraints, deterministic edge deduplication, conflict-aware property management, and fine-grained provenance preserve issuer identity, reporting-period validity, and traceability to source evidence. The contributions of this work comprise the proposed methodology for financial knowledge graph construction, the creation of an evidence-grounded temporal knowledge graph from heterogeneous financial documents, and an intrinsic framework for evaluating the quality of the resulting graph. The evaluation framework assesses seven weighted dimensions, two hard validation gates, and structural diagnostics. By separating graph-quality assessment from downstream retrieval and answer generation, the framework supports systematic diagnosis and iterative refinement of the constructed graph.

### DistDNA: Language Model Fingerprinting under Stochastic Decoding

**中文标题：** DistDNA：随机解码下的语言模型指纹

**摘要：** Behavioral fingerprints identify a large language model (LLM) from its responses to a shared set of prompts, enabling applications such as verifying whether a deployed model corresponds to the checkpoint it claims to be. Deployed models, however, are commonly served with stochastic decoding, under which the same model may produce different responses to an identical prompt, depending on an unknown temperature and top-$p$ setting. Existing representations such as LLM DNA provide limited treatment of this variation. A natural remedy is to characterize models by their response distributions, which, however, raises two challenges. First, each distribution must be estimated from only a small number of sampled responses. Second, a change in decoding setting can alter responses to the same extent as a change of checkpoint. Consequently, fingerprint distances alone provide an incomplete basis for model identity, and identification typically relies on a classifier trained jointly on fingerprints from many checkpoints. We propose DistDNA, which represents a model by its prompt-conditional response distributions and compares models by promptwise maximum mean discrepancy (MMD). The model under examination is assigned to the known checkpoint whose reference fingerprints, collected at several decoding settings, lie nearest to its own, without training a classifier. We show that finite sampling adds variance-dependent terms to the expected squared fingerprint distance, with these terms decreasing as $O(1/R)$ for equal response counts, where $R$ is the number of responses per prompt. Experiments across 115 model checkpoint entries demonstrate that DistDNA improves identification accuracy over the strongest baseline, LLM DNA, by 10.36%.

**摘要翻译：** 行为指纹根据对一组共享提示的响应来识别大型语言模型 (LLM)，从而支持验证部署的模型是否与其声称的检查点相对应等应用程序。然而，部署的模型通常采用随机解码，在这种解码下，同一模型可能会对相同的提示产生不同的响应，具体取决于未知的温度和 top-$p$ 设置。现有的表征（例如 LLM DNA）对这种变异的处理有限。一种自然的补救措施是通过响应分布来表征模型，但这提出了两个挑战。首先，每个分布必须仅根据少量抽样响应来估计。其次，解码设置的改变可以改变响应，其程度与检查点的改变相同。因此，指纹距离本身无法为模型身份提供完整的基础，并且识别通常依赖于对来自许多检查点的指纹进行联合训练的分类器。我们提出了 DistDNA，它通过即时条件响应分布来表示模型，并通过即时最大平均差异（MMD）来比较模型。正在检查的模型被分配给已知的检查点，其在多个解码设置下收集的参考指纹最接近其自身的指纹，而无需训练分类器。我们表明，有限采样将方差相关项添加到预期的指纹平方距离中，对于相同的响应计数，这些项减少为 $O(1/R)$，其中 $R$ 是每个提示的响应数。跨 115 个模型检查点条目的实验表明，与最强基线 LLM DNA 相比，DistDNA 的识别准确度提高了 10.36%。

### Evaluating Prompting Strategies for Zero-Shot Multilingual Aspect-Based Sentiment Analysis with Large Language Models

**中文标题：** 使用大型语言模型评估零样本多语言基于方面的情感分析的提示策略

**摘要：** While large language models (LLMs) have advanced natural language understanding, their ability to perform complex target-aspect-sentiment detection (TASD) -- a key task within aspect-based sentiment analysis (ABSA) -- in zero-shot multilingual settings remains underexplored. Existing ABSA research predominantly focuses on English or relies on fine-tuned task-specific models, leaving a gap in understanding how open-weight LLMs handle compound sentiment triplet extraction across diverse language families and domains. We present a systematic evaluation of zero-shot multilingual TASD across 12 languages and three domains using seven instruction-tuned open-weight models -- ranging from 8B to 35B parameters across dense and mixture-of-experts (MoE) architectures -- under four prompting paradigms: monolithic, chain-of-thought, sequential, and sequential refine. Our results show that direct monolithic prompting achieves strong zero-shot performance, outperforming multi-step pipelines, while dense models consistently outperform sparse MoE architectures. Through fine-grained error taxonomy profiling and step-level pipeline tracking, we demonstrate that initial aspect term recall forms a hard bottleneck, whereas multi-step decomposition degrades extraction quality; iterative refinement only partially recovers this loss on larger models while inducing net-negative over-refinement on smaller architectures. Finally, generation volume analysis shows that multi-step strategies incur up to 2.38x token overhead without F1 gains, establishing monolithic prompting as the most effective and efficient paradigm for multilingual ABSA.

**摘要翻译：** 虽然大型语言模型 (LLM) 具有先进的自然语言理解能力，但它们在零样本多语言设置中执行复杂的目标方面情感检测 (TASD)（基于方面的情感分析 (ABSA) 中的一项关键任务）的能力仍未得到充分探索。现有的 ABSA 研究主要集中在英语或依赖于微调的特定任务模型，在理解开放权重法学硕士如何处理跨不同语言家族和领域的复合情感三元组提取方面存在差距。我们使用七个指令调整的开放权重模型（跨密集和专家混合 (MoE) 架构，从 8B 到 35B 参数）在四种提示范式下对 12 种语言和 3 个领域的零样本多语言 TASD 进行了系统评估：单一、思想链、顺序和顺序细化。我们的结果表明，直接整体提示实现了强大的零样本性能，优于多步管道，而密集模型始终优于稀疏 MoE 架构。通过细粒度的错误分类分析和步骤级管道跟踪，我们证明初始方面术语回忆形成了硬瓶颈，而多步骤分解会降低提取质量；迭代细化只能部分恢复较大模型上的这种损失，同时会导致较小架构上的净负过度细化。最后，生成量分析表明，多步骤策略在没有 F1 增益的情况下会产生高达 2.38 倍的代币开销，从而将整体提示确立为多语言 ABSA 最有效和高效的范例。
