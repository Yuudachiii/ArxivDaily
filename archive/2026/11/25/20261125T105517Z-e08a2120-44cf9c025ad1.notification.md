### DiaCap: Jointly Learning Who Speaks When for Audiovisual Dialogue Captioning

**中文标题：** DiaCap：共同学习谁在何时发言以进行视听对话字幕

**摘要：** We present DiaCap, an audiovisual LLM for comprehensive dialogue captioning, which produces the transcript, timestamps, and a visual description of the speaker for every utterance in a video. Considering that utterance timing and audiovisual diarization are tightly coupled, DiaCap unifies the tasks in a single model, trained in two complementary stages. First, we train DiaCap on 225K curated clips, using synthetic captions that densely label every utterance in detail. Second, we further refine the model via reinforcement learning on 2.9K human-corrected clips, using fine-grained feedback that directly evaluates utterance timing, speaker grouping, and speaker binding. On DiaDemBench, which we extend with utterance-level timestamps and subtitle redaction, both DiaCap with off-the-shelf transcripts and its end-to-end variant DiaCap-E2E achieve strong results. Specifically, DiaCap performs on par with Gemini 4 Argon in audiovisual diarization while clearly outperforming it in timestamp accuracy (76.59 vs. 42.76 TIME). It also maintains strong diarization on multilingual and minute-long videos, and transfers to audiovisual question answering.

**摘要翻译：** 我们推出 DiaCap，一种用于全面对话字幕的视听法学硕士，它可以为视频中的每句话生成文字记录、时间戳和讲话者的视觉描述。考虑到话语计时和视听二化是紧密耦合的，DiaCap 将任务统一在一个模型中，并在两个互补的阶段进行训练。首先，我们在 225K 个精选剪辑上训练 DiaCap，使用密集地详细标记每个话语的合成字幕。其次，我们通过对 2.9K 人工校正剪辑进行强化学习，使用直接评估说话时间、说话者分组和说话者绑定的细粒度反馈来进一步完善模型。在 DiaDemBench 上，我们通过话语级时间戳和字幕编辑进行了扩展，具有现成转录本的 DiaCap 及其端到端变体 DiaCap-E2E 都取得了出色的结果。具体来说，DiaCap 在视听二值化方面的表现与 Gemini 4 Argon 相当，而在时间戳精度方面则明显优于 Gemini 4 Argon（76.59 与 42.76 TIME）。它还对多语言和一分钟长的视频保持强烈的分类，并转移到视听问答。

### SAG-Mem-1.0 Technical Report

**中文标题：** SAG-Mem-1.0技术报告

**摘要：** Long-term conversational memory requires retrieving complementary facts scattered across dialogue sessions, including intermediate evidence with limited similarity to the original question. Existing approaches often rely on derived memory representations or persistent relational structures, introducing construction costs and potentially losing source details. We present SAG-Mem, a conversational memory framework that preserves complete dialogue messages in non-overlapping chunks and discovers complementary evidence through query-time lexical expansion. Memory construction requires no model inference, using a lexical index without LLM-based extraction, summarization, or semantic relation construction. At query time, BM25 retrieves initial candidates, an evidence evaluator identifies useful chunks, and lexical cues from selected evidence guide an additional retrieval round. Retrieved dialogue is further annotated with calendar interpretations of supported relative-time expressions, preserving the original wording and temporal granularity. We also introduce SAG-Mem-Lite, an alternative configuration that replaces evidence scoring with embedding-based candidate scoring, achieving lower operational cost than Full Context and all memory-based baselines across both benchmarks with low query latency. On LoCoMo and LongMemEval, SAG-Mem achieves overall scores of 83.08 and 80.20, respectively, the highest among the evaluated methods on both benchmarks. On LongMemEval, it exceeds the strongest compared baseline by 7.20 points. SAG-Mem-Lite achieves scores of 77.09 and 77.20, respectively. These results support dialogue preservation and evidence-guided retrieval expansion as an effective design for long-term conversational memory.

**摘要翻译：** 长期对话记忆需要检索分散在对话会话中的补充事实，包括与原始问题相似性有限的中间证据。现有的方法通常依赖于派生的内存表示或持久的关系结构，从而引入构建成本并可能丢失源细节。我们提出了 SAG-Mem，一个会话记忆框架，它在不重叠的块中保留完整的对话消息，并通过查询时词汇扩展发现补充证据。内存构建不需要模型推理，使用词法索引，无需基于 LLM 的提取、摘要或语义关系构建。在查询时，BM25 检索初始候选，证据评估器识别有用的块，并且来自所选证据的词汇线索指导额外的检索轮次。检索到的对话进一步用支持的相对时间表达式的日历解释进行注释，保留了原始措辞和时间粒度。我们还引入了 SAG-Mem-Lite，这是一种替代配置，它用基于嵌入的候选评分取代了证据评分，实现了比完整上下文和跨两个基准测试的所有基于内存的基线更低的运营成本，并且查询延迟较低。在 LoCoMo 和 LongMemEval 上，SAG-Mem 的总体得分分别为 83.08 和 80.20，是这两个基准测试的评估方法中最高的。在 LongMemEval 上，它比最强的比较基线高出 7.20 个点。 SAG-Mem-Lite 的得分分别为 77.09 和 77.20。这些结果支持对话保存和证据引导检索扩展作为长期对话记忆的有效设计。

### MetaFORGE: A Meta-Learning Framework for Harness Optimization in Automated Code Generation for Parallel Computing

**中文标题：** MetaFORGE：并行计算自动代码生成中利用优化的元学习框架

**摘要：** Large language models (LLMs) can generate parallel programs, but their correctness and performance depend strongly on the instructions that guide generation. We present \textsc{MetaFORGE}, an execution-grounded meta-learning framework that iteratively optimizes persistent natural-language skill specifications for MPI C code generation. \textsc{MetaFORGE} combines correctness testing, compiler diagnostics, static-analysis findings, runtime measurements, and rank-level load-imbalance profiles into a scalar reward that drives textual-gradient refinement, while an external memory distills and retrieves reward-supported optimization knowledge across runs.
  Across six MPI tasks and three workload sizes, \textsc{MetaFORGE} improves static-analysis quality, runtime, and load balance relative to zero-shot generation and generally exceeds the evaluated \textsc{TextGrad} iterative baseline. A model-matched refinement ablation shows that the MetaFORGE advantage persists when its refinement model is reduced to \texttt{gpt-4o}. An expanded retrieval ablation across all 18 task--workload configurations shows consistent runtime benefit and broad static-analysis and load-balance benefit from retrieved context. Leakage-controlled held-out and zero-update experiments further provide evidence that optimization knowledge persists in both the transferred skill and external memory under the evaluated protocol.

**摘要翻译：** 大型语言模型 (LLM) 可以生成并行程序，但其正确性和性能在很大程度上取决于指导生成的指令。我们提出了 \textsc{MetaFORGE}，一个基于执行的元学习框架，它迭代地优化 MPI C 代码生成的持久自然语言技能规范。 \textsc{MetaFORGE} 将正确性测试、编译器诊断、静态分析结果、运行时测量和排名级别负载不平衡配置文件结合到一个标量奖励中，驱动文本梯度细化，同时外部存储器在运行过程中提取和检索奖励支持的优化知识。
  在六个 MPI 任务和三个工作负载大小中，相对于零样本生成，\textsc{MetaFORGE} 提高了静态分析质量、运行时间和负载平衡，并且通常超过了评估的 \textsc{TextGrad} 迭代基线。模型匹配的细化消融表明，当其细化模型简化为 \texttt{gpt-4o} 时，MetaFORGE 的优势仍然存在。跨所有 18 个任务工作负载配置的扩展检索消融显示了一致的运行时优势以及检索上下文带来的广泛静态分析和负载平衡优势。泄漏控制的保留和零更新实验进一步提供了证据，证明在评估的协议下，优化知识在转移的技能和外部记忆中持续存在。

### Draft Calibration for Speculative Decoding: Accelerating LLM Serving by Matching Draft and Target Distributions

**中文标题：** 推测性解码的草稿校准：通过匹配草稿和目标分布来加速 LLM 服务

**摘要：** Speculative decoding accelerates large language model (LLM) inference by employing a lightweight draft model to propose draft tokens and allowing the target model to verify the new tokens in parallel to improve inference-time compute utilization. The speedup relies on the acceptance probability of draft tokens in target verification, which is directly related to the gap $\|p-q\|_1$ between the target distribution $p$ and the draft distribution $q$. In this paper, we study draft calibration of speculative decoding to improve the speedup of speculative decoding, where we employ post-hoc methods to calibrate the draft distribution to mitigate the distribution gap. We observe that though current community open-source draft models may learn the top candidate token correctly, they are generally underconfident compared to the target model, suggesting a consistent distribution mismatch. To mitigate the effect of this mismatch on the acceptance rate of the draft models, we try various post-hoc calibration methods, including standard temperature scaling and token-wise calibration. Our results suggest that a standard temperature scaling applied to the draft distribution improves the acceptance length by up to approximately 10\% with almost no additional cost across different tasks. Throughput analysis further verifies that this improvement in serving efficiency. Analysis of more general calibration methods reveals further potential room for improvement.

**摘要翻译：** 推测性解码通过采用轻量级草稿模型来提出草稿令牌并允许目标模型并行验证新令牌以提高推理时间计算利用率，从而加速大型语言模型 (LLM) 推理。加速依赖于目标验证中草案代币的接受概率，该概率与目标分布 $p$ 和草案分布 $q$ 之间的差距 $\|p-q\|_1$ 直接相关。在本文中，我们研究推测解码的草案校准以提高推测解码的加速，其中我们采用事后方法来校准草案分布以缩小分布差距。我们观察到，尽管当前的社区开源草案模型可以正确学习顶级候选令牌，但与目标模型相比，它们通常缺乏信心，这表明存在一致的分布不匹配。为了减轻这种不匹配对模型草案接受率的影响，我们尝试了各种事后校准方法，包括标准温度缩放和令牌明智校准。我们的结果表明，应用于草稿分布的标准温度缩放将接受长度提高了大约 10%，而在不同的任务中几乎没有额外的成本。吞吐量分析进一步验证了服务效率的提高。对更通用的校准方法的分析揭示了进一步的潜在改进空间。

### AIChipBench: Benchmarking LLM Agents for Automated AI Accelerator Design

**中文标题：** AIChipBench：自动化 AI 加速器设计的 LLM 代理基准测试

**摘要：** A language-model decoder carries state between decoding steps, and in hardware a wrong state update can leave the current token correct and corrupt the output several tokens later, so a design can pass output tests and still be wrong. AIChipBench asks what LLM coding agents need to build such hardware correctly. Agents implement quantized Qwen3.5, Gemma 3, Gemma 4, and Llama 3.2 decoders in synthesizable register-transfer-level (RTL) code against an executable integer reference that specifies the outputs and the stored state at every decoding step. They debug against public tests under fixed budgets; their frozen designs are graded on held-out token sequences, resets, memory stalls, and synthesis, and a second track asks them to speed up a correct design at nearly fixed area. Across 9,136 attempts by four coding agents, the difficulty lies in stored state. Feedback that points to the first state mismatch raises acceptance over output-only feedback in all 12 agent--task cells of a matched study, by 25.0 to 46.9 percentage points, and halves the agent-hours per accepted design. Regraded on new sequences and conditions, 45 of 69 accepted designs fail within the 32 steps their tests required. More than a third of attempts to speed up a correct design end without one. An overall score ranks Sol 5.6 and Fable 5.1 above Astra 6 and Opus 5.5, and both halves of the instances give this order in all 200 random splits. Hardware agents therefore need debugging feedback that exposes stored state, and their benchmarks need final tests well beyond the development cases.

**摘要翻译：** 语言模型解码器在解码步骤之间携带状态，并且在硬件中，错误的状态更新可能使当前令牌保持正确，并在以后损坏几个令牌的输出，因此设计可以通过输出测试，但仍然是错误的。 AIChipBench 询问 LLM 编码代理需要什么才能正确构建此类硬件。代理在可合成的寄存器传输级 (RTL) 代码中针对指定每个解码步骤的输出和存储状态的可执行整数引用来实现量化 Qwen3.5、Gemma 3、Gemma 4 和 Llama 3.2 解码器。他们在固定预算下针对公开测试进行调试；他们的冻结设计根据保留的令牌序列、重置、内存停顿和综合进行评分，第二条轨道要求他们在几乎固定的区域加速正确的设计。在 4 个编码代理的 9,136 次尝试中，困难在于存储状态。指向第一个状态不匹配的反馈使匹配研究的所有 12 个代理任务单元中对仅输出反馈的接受度提高了 25.0 至 46.9 个百分点，并且每个接受的设计的代理时间减少了一半。根据新的顺序和条件重新评级，69 个已接受的设计中有 45 个未达到测试要求的 32 个步骤。超过三分之一的加速正确设计的尝试都以失败告终。总体得分将 Sol 5.6 和 Fable 5.1 排在 Astra 6 和 Opus 5.5 之上，并且两个实例在所有 200 个随机分割中都给出了这个顺序。因此，硬件代理需要公开存储状态的调试反馈，并且它们的基准测试需要远远超出开发案例的最终测试。

### Shifter Quantization: Compact Representations for Native Integer Computation

**中文标题：** 移位器量化：本机整数计算的紧凑表示

**摘要：** Groupwise quantization is used in LLM quantization to improve accuracy at low bit widths, but grouping weights keeps standard integer MMA from spanning the full dot product for efficient GPU inference. We develop a new quantization method, Shifter Quantization (SQ), that reconstructs native-width integer operands by appending and shifting shared bits. To further extend the efficiency, we develop a special variant of SQ, Shifter Integer (SHI), to use INT4 kernels. We show that SQ and SHI formats perform better than standard groupwise quantization in quality, as measured by projection error and KL divergence, and in inference speed, as measured during decoding and prefill. For low precision like 2-bit quantization, SQ2 and SHI2 achieve 2.71-3.77x the 4,096-token prefill throughput of llama.cpp on a Q2_K checkpoint and reduce WikiText-2 KL by 6.6-7.8%. For mid precision like 4-bit quantization, SQ4 achieves 1.43-2.47x the prefill throughput of NInfer's groupwise-integer baselines across the tested models and prompt lengths, with 24-40% lower KL than the NInfer baselines. For high precision like 8-bit quantization, SQ8 achieves 27.4% higher batch-one prefill throughput and 72.7% lower KL than vLLM's online FP8.

**摘要翻译：** LLM 量化中使用分组量化来提高低位宽下的精度，但分组权重使标准整数 MMA 无法跨越全点积以实现高效的 GPU 推理。我们开发了一种新的量化方法，移位量化（SQ），它通过附加和移位共享位来重建本机宽度整数操作数。为了进一步提高效率，我们开发了 SQ 的特殊变体，移位整数 (SHI)，以使用 INT4 内核。我们表明，SQ 和 SHI 格式在质量（通过投影误差和 KL 散度测量）以及推理速度（在解码和预填充期间测量）方面表现优于标准分组量化。对于 2 位量化等低精度，SQ2 和 SHI2 在 Q2_K 检查点上实现了 llama.cpp 4,096 个令牌预填充吞吐量的 2.71-3.77 倍，并将 WikiText-2 KL 减少了 6.6-7.8%。对于 4 位量化等中等精度，SQ4 在测试模型和提示长度中实现了 NInfer 分组整数基线的 1.43-2.47 倍预填充吞吐量，KL 比 NInfer 基线低 24-40%。对于 8 位量化等高精度，SQ8 的批量一预填充吞吐量比 vLLM 的在线 FP8 高 27.4%，KL 低 72.7%。

### FOL-Proof: Verifying LLM Text-to-Logic Translations via Deterministic Semantics

**中文标题：** FOL-Proof：通过确定性语义验证 LLM 文本到逻辑的翻译

**摘要：** Large Language Models (LLMs) are increasingly used to translate natural-language statements into first-order logic (FOL) to improve reasoning. However, LLMs are prone to errors, and so a semantically unfaithful FOL formula could corrupt downstream reasoning. We present FOL-Proof, a semantic firewall pipeline that validates LLM-generated FOL translations against independently derived linguistic interpretations. FOL-Proof operates by deterministically obtaining a pool of candidate translations via semantic analysis tools, such as the English Resource Grammar and Minimal Recursion Semantics; then applying an SMT solver to check each derived reading for logical equivalence to the LLM-generated formula. If the translation is faithful it is accepted; otherwise, it is rejected, or optionally repaired via repeated invocations to the LLM. The procedure is conservative: incomplete search, unsupported constructions, or inconclusive checks yield abstention rather than false rejection. We evaluated FOL-Proof on established benchmarks (ProofWriter, RuleTaker and PrOntoQA), and also on a new adversarial benchmark (LongFaithCheck). Our experiments show that FOL-Proof attains near perfect selective accuracy, while direct LLM judges and round-trip baselines show substantially worse performance.

**摘要翻译：** 大型语言模型 (LLM) 越来越多地用于将自然语言语句转换为一阶逻辑 (FOL) 以改进推理。然而，LLM 很容易出错，因此语义上不忠实的 FOL 公式可能会破坏下游推理。我们提出了 FOL-Proof，一种语义防火墙管道，可根据独立派生的语言解释来验证 LLM 生成的 FOL 翻译。 FOL-Proof 的运行方式是通过语义分析工具（例如英语资源语法和最小递归语义）确定性地获取候选翻译池；然后应用 SMT 求解器检查每个导出的读数与 LLM 生成的公式的逻辑等价性。如果翻译忠实，则被接受；否则，它会被拒绝，或者可以选择通过重复调用 LLM 来修复。该程序是保守的：不完整的搜索、不受支持的结构或不确定的检查会产生弃权而不是错误拒绝。我们根据既定基准（ProofWriter、RuleTaker 和 PrOntoQA）以及新的对抗性基准（LongFaithCheck）评估了 FOL-Proof。我们的实验表明，FOL-Proof 达到了近乎完美的选择准确性，而直接 LLM 法官和往返基线的性能则要差得多。

### Auditing the Judge: Human-Derived Bias Discovery, Quantification, and Mitigation in LLM Judges

**中文标题：** 审计法官：法学硕士法官中人为偏见的发现、量化和缓解

**摘要：** While Large Language Models (LLMs) are increasingly deployed as automated evaluators in evaluation and training pipelines, their judgements are often affected by systematic biases that conflict with human preferences. Although prior work has identified various biases and proposed methods for detecting and mitigating them, less attention has been paid to using human preferences to inform bias identification and mitigation. Moreover, these approaches rely heavily on pre-discovered bias lists, overlook bias strength, and depend on costly interventions. In this work, we propose HUB-J, an integrated framework based on human-derived bias factors that detects, quantifies, and mitigates biases in LLM-as-a-Judge systems. Our approach leverages human-LLM judgement disagreement cases to automatically discover interpretable bias factors, and utilizes agreement cases to quantify bias strength through controlled input modifications and resulting shifts in model decisions. Finally, building on these quantified biases, we introduce a lightweight, training-free regression-based mitigation strategy that estimates the influence of each bias factor on model judgments and corrects bias-influenced decisions by removing its estimated effect. Empirical results show that HUB-J uncovers both known and novel bias factors, reveals meaningful differences in model susceptibility, and consistently reduces bias-driven decision flips while generalizing across models.

**摘要翻译：** 虽然大型语言模型 (LLM) 越来越多地被部署为评估和培训流程中的自动评估器，但它们的判断往往受到与人类偏好相冲突的系统偏差的影响。尽管之前的工作已经识别了各种偏见并提出了检测和减轻这些偏见的方法，但很少有人关注利用人类偏好来识别和减轻偏见。此外，这些方法严重依赖于预先发现的偏见列表，忽视了偏见的强度，并且依赖于昂贵的干预措施。在这项工作中，我们提出了 HUB-J，这是一个基于人为​​偏见因素的综合框架，可以检测、量化和减轻法学硕士法官系统中的偏见。我们的方法利用人类法学硕士判断分歧案例来自动发现可解释的偏差因素，并利用协议案例通过受控输入修改和模型决策中产生的变化来量化偏差强度。最后，在这些量化偏差的基础上，我们引入了一种轻量级、免训练的基于回归的缓解策略，该策略估计每个偏差因素对模型判断的影响，并通过消除其估计影响来纠正受偏差影响的决策。实证结果表明，HUB-J 揭示了已知和新的偏差因素，揭示了模型敏感性中有意义的差异，并在跨模型进行泛化时一致减少了偏差驱动的决策翻转。

### U-Statistics-Powered LLM Reasoning

**中文标题：** U-统计驱动的法学硕士推理

**摘要：** Since its introduction by DeepSeek, group relative policy optimization (GRPO) has been widely adopted for training large reasoning models and agents, spurring a proliferation of its variants. Yet the group size, a crucial hyperparameter in these GRPO-type algorithms, remains largely chosen by trial and error. Exploiting the U-statistic structure of GRPO's policy gradient, we recast the selection of the group size as a classical statistical problem of variance ratio estimation. This problem is particularly challenging when the denominator of the ratio is small, rendering naive plug-in estimators unstable. To address this challenge, we propose a pessimistic ratio estimator that accounts for the denominator's estimation uncertainty. We characterise the statistical properties of this estimator across three sample-size regimes. Empirically, using %a jackknife-based pessimistic rule on synthetic tasks from Reasoning Gym and real-world benchmarks covering both mathematical reasoning and code generation, we show that our adaptive group size selection reduces the mean squared error of the resulting policy gradient and improves policy optimisation over fixed-group-size baselines, with modest additional computational cost.

**摘要翻译：** 自从 DeepSeek 推出以来，组相对策略优化（GRPO）已被广泛用于训练大型推理模型和代理，从而刺激了其变体的激增。然而，组大小作为这些 GRPO 类型算法中的一个关键超参数，在很大程度上仍然是通过反复试验来选择的。利用 GRPO 策略梯度的 U 统计结构，我们将群体大小的选择重新定义为方差比估计的经典统计问题。当比率的分母很小时，这个问题尤其具有挑战性，导致简单的插件估计器不稳定。为了应对这一挑战，我们提出了一种悲观比率估计量，它可以解释分母的估计不确定性。我们描述了该估计量在三个样本大小范围内的统计特性。根据经验，在 Reasoning Gym 的合成任务和涵盖数学推理和代码生成的现实世界基准上使用基于折刀的悲观规则，我们表明，我们的自适应组大小选择减少了所得策略梯度的均方误差，并在固定组大小基线上改进了策略优化，并且具有适度的额外计算成本。

### Understanding Clipping In Zeroth-Order Optimization

**中文标题：** 了解零阶优化中的裁剪

**摘要：** Zeroth-order optimization has emerged as a resource-efficient alternative to Stochastic Gradient Descent (SGD) when fine-tuning LLMs, thanks to the inherent low dimensionality of the loss landscape. It relies on a two-point estimate of the gradient that only accesses the function value and not the gradient, bypassing the resource-heavy backpropagation. Recently, it was accidentally discovered that per-sample clipping can improve the performance of the trained model, while running a differentially private version of zeroth-order optimization \cite{zhang2024dpzero} with a very large privacy parameter $ε$ (corresponding to very little privacy). In this paper, we systematically investigate this phenomenon and demonstrate that ($i$) the optimal choice of learning rate $η$ is inversely proportional to the clipping threshold $c$, satisfying $ηc =$ constant; ($ii$) clipping drives the zeroth-order optimization to a different solution with higher test accuracy; and ($iii$) this phenomenon is only observed with per-sample clipped zeroth-order optimization and not other zeroth-order alternatives that also provide robust estimates of the gradient. Further analyses with artificially injected label noise reveals that clipping leads to more robust predictions, which stems from the implicit down weighting of hard-to-fit training examples. Our code is available at https://github.com/SewoongLab/ClipZero

**摘要翻译：** 由于损失景观固有的低维性，在微调 LLM 时，零阶优化已成为随机梯度下降 (SGD) 的资源高效替代方案。它依赖于梯度的两点估计，仅访问函数值而不访问梯度，从而绕过了资源密集型的反向传播。最近，偶然发现按样本裁剪可以提高训练模型的性能，同时运行具有非常大的隐私参数$ε$（对应于非常小的隐私）的零阶优化的差分隐私版本\cite{zhang2024dpzero}。在本文中，我们系统地研究了这一现象，并证明（$i$）学习率$η$的最优选择与裁剪阈值$c$成反比，满足$ηc =$常量； ($ii$) 裁剪将零阶优化驱动到具有更高测试精度的不同解决方案； ($iii$) 这种现象仅在每个样本裁剪的零阶优化中观察到，而在其他也提供鲁棒梯度估计的零阶替代方案中则观察不到。对人工注入标签噪声的进一步分析表明，裁剪可以带来更稳健的预测，这源于难以拟合的训练示例的隐式权重下降。我们的代码位于 https://github.com/SewoongLab/ClipZero
